Origen, actualización y trazabilidad

Cargando estado del servicio...

Extractor automático v0.4 para Windows: el código y la guía de instalación están en CAHOS / extractor. Primero valida la conexión con PROBAR_CONEXION.bat en una computadora institucional. GitHub Pages permanece sin datos reales hasta disponer de una API HTTPS autenticada.

Seguridad operativa

GitHub Pages no ejecuta el servidor OLAP. El visor requiere una API institucional HTTPS, con autenticación, controles de acceso y autorización de origen. Las consultas se generan a partir de dimensiones y miembros verificados por el catálogo OLAP. El conector PowerShell únicamente ejecuta consultas de lectura SELECT. El extractor local puede reutilizar una conexión OLAP guardada en un Excel seleccionado por el usuario; esta nunca se envía a GitHub Pages. Requiere conexión vigente y proveedor MSOLAP en Windows.

Fuentes territoriales y denominadores

Cartografía municipal: INEGI Marco Geoestadístico, 72 municipios. Denominadores por edad, sexo y año: proyecciones COESPO/CONAPO 2015–2030, importadas localmente con IMPORTAR_POBLACION.bat. Tasas solo con estratos compatibles y fuente identificada.

SEED y LESP: integración pendiente de validación

SEED 2026: tablas dinámicas de mortalidad, sin causa básica CIE-10 identificada en el archivo proporcionado. No se asignan defunciones a padecimientos SUIVE. LESP: informe con nombres y folios; no se publica ni se carga a la página pública de GitHub, requiere un proceso protegido de agregación, conciliación y eliminación de identificadores.

Advertencias epidemiológicas

Las cifras representan notificaciones del sistema según la medida Casos; no equivalen necesariamente a individuos únicos. No se suman tasas ni denominadores repetidos. Un año parcial no es comparable con uno completo a menos que se limite el mismo periodo. El momento de descarga no sustituye el corte oficial de publicación.
